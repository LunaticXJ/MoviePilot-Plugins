# MoviePilot-Plugin-Market

MoviePilot三方插件市场：https://github.com/LunaticXJ/MoviePilot-Plugins

### 插件列表
1. Strm生成器 v1.0 `实时监控、定时全量增量生成strm文件。`
2. Emby最新媒体排序 v1.0.0 `将Emby媒体加入时间设置为发布时间，让首页最新媒体列表按发布日期倒序排列。`
3. Emby剧集缺集检查 v1.0.0 `查找Emby库中电视剧缺失的集/断集情况，支持数据看板展示和文件导出。`
4. Emby多版本媒体检查 v1.0.0 `查找Emby库中重复/多版本电影与电视剧，支持数据看板展示与文件导出。`
